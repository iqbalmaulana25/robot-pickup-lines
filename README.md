Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

`main.ts` (Node 22, no dependencies) writes one pickup line — at most 200
characters — in the voice of a robot, to `/output/entry.txt`. The line
turns the one commitment every computer dodges, a software update, into
the compliment.

Run it with:

```sh
node main.ts
```
